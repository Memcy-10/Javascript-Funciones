# Clases JavaScript — SENA Programa 3406211

Repositorio de materiales del curso de JavaScript del programa **3406211** del SENA.  
Incluye ejemplos de clase, ejercicios propuestos y proyectos de depuración para estudiantes.

---

## Cómo ejecutar los archivos

**Archivos `.js` independientes** (ejemplos y ejercicios):

```bash
node ruta/al/archivo.js
```

**Proyectos web** (carpeta `0_Proyectos_a_corregir_mejorar/`):  
Abrir el archivo `.html` directamente en el navegador. No requieren servidor ni instalación.
